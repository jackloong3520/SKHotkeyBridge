# 常见问题与排错

## 提示"未找到 MacKMLink.exe"

原因：原版对拷线没运行，或窗口类名 / 进程名与配置不符。

1. 确认 `SKLoader.exe` 已启动且对拷线已连接。
2. 运行 `SKHotkeyBridge.exe --check-target`，正常应输出 `hwnd`、`pid`、`path`。
3. 若输出 `"found": false`，说明窗口类名或进程名不匹配，按 README「适配其他版本」一节核对。

## 按快捷键没反应

按顺序排查：

1. **热键被占用。** 换一个组合（如 `Ctrl+Alt+Shift+F11`）试试。若启动后弹窗提示"注册失败"，就是被占用了。
2. **权限不一致。** 若原程序以管理员运行，桥接也必须"以管理员身份运行"。工具会自动检测并弹窗提示。
3. **罗技按键映射未生效。** 先在键盘上按一次 `Ctrl+Alt+F11` 验证工具本身；键盘能触发、鼠标不能，则是罗技侧配置问题。
4. **原程序版本不同。** 命令号变更会导致 `WM_COMMAND` 无效，用 `--check-target` 与 `--state` 定位。

## 托盘图标找不到

- 被 Windows 折叠进了托盘的隐藏区，点托盘的 `^` 展开，把图标拖回任务栏。
- 资源管理器重启后图标可能丢失：程序监听了 `TaskbarCreated` 消息会自动重建；若仍没有，重启一次桥接程序即可。

## 屏幕上残留了一个菜单

极端情况下（如读取过程被强杀）可能留下原程序的菜单。按一次 `Esc`，或点一下桌面空白处即可关闭。程序每次读取前也会自动清理上次遗留的菜单。

## 状态显示"未知"

说明读取托盘菜单失败。可能原因：

- 原程序正忙、或处于未连接状态
- `TrayMessage` / `TrayIconId` 与实际版本不符

可将 `[State] Detection` 设为 `off` 临时退回"直接两项各切一次"的模式，代价是两项可能不同步。

## 杀毒软件报毒

PyInstaller 打包产物常被启发式引擎误报，属常见现象。处理方式：

- 用 Release 页面提供的 SHA-256 校验文件
- 或直接用本仓库源码自行构建（源码完全开放，可自行审查）

## 想换掉默认快捷键

编辑 `SKHotkeyBridge.ini` 的 `[Hotkeys]` 段，保存后托盘右键 → "重新载入配置"。三个快捷键均可留空停用，但至少要保留一个。

## 支持哪些 Windows 版本

在 Windows 11 64 位实测通过。依赖的 `RegisterHotKey` / `Shell_NotifyIconW` 均为长期稳定的 Win32 API，Windows 10 应同样可用。仅支持 64 位 Windows（源码中的句柄类型按 64 位显式声明）。
